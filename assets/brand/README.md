# Brand Assets

This directory contains the Research With Coding Agents toolkit logo variants.

The source mark was provided by the project owner and normalized into repository-ready PNG assets for public documentation and release surfaces.

- `rwca-logo.png`: primary README and documentation logo on a white background.
- `rwca-logo-transparent.png`: transparent line-art variant for layouts that need alpha compositing.
- `rwca-icon.png`: square icon variant for compact surfaces.

These assets identify Research With Coding Agents. They are not Markplane, Superpowers, Codex, Claude Code, Gemini, or Antigravity logos, and do not imply endorsement by those projects or vendors.
